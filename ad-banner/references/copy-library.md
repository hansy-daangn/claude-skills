# 카피 라이브러리 (캠페인별 적용 사례)

> **이 파일은 phrasebook이 아니다.**  
> `foundation-voice-tone.md`의 작동 원리를 캠페인 컨텍스트에 *적용한 사례*만 모은다. 표현을 그대로 복붙하면 안 된다. 캠페인이 다르면 결과 1줄을 새로 적은 뒤 voice-tone 원리로 재도출한다.

---

## 0. 사용 원칙 (반드시 지킬 것)

카피(헤드 / 서브 / CTA)를 만들 때 **가장 먼저** `foundation-voice-tone.md`를 펼친다.

| 무엇이 필요한가 | 어디서 봐야 하는가 |
|---|---|
| 헤드 4가지 패턴 (질문 / 상황 / 이웃 / 구체) | foundation-voice-tone.md §3 |
| 헤드 비율별 길이 룰 | foundation-voice-tone.md §4 |
| **CTA 4가지 후킹 패턴 + 4단계 생성 프로세스** | **foundation-voice-tone.md §5** |
| **CTA 자가 검증 6개** | **foundation-voice-tone.md §5-3** |
| 절대 금지 카피 (공짜 / 과장 / 외국어 / 미완성형 등) | foundation-voice-tone.md §6 |
| 카피 패키지 자가 검증 9개 | foundation-voice-tone.md §7 |

이 파일은 voice-tone 원리가 캠페인별로 *어떻게 풀렸는지*를 보여줄 뿐, 정답을 정의하지 않는다.

---

## 사용 흐름

1. STEP 1에서 캠페인 주제·결과 추출.
2. **foundation-voice-tone.md를 먼저 펼친다.** (위 표 참조)
3. 아래 카테고리 중 본인 캠페인과 가장 가까운 곳 선택.
4. "캠페인 결과 후보"를 그대로 쓰지 말고, **자기 캠페인에 맞는 결과 1줄을 새로 적는다.**
5. voice-tone §3 (헤드) + §5 (CTA 후킹+프로세스) 원리로 헤드·서브·CTA 도출.
6. voice-tone §5-3 + §6 + §7 자가 검증 통과 확인.
7. 통과하면 figma-generator로 투입.

> **중요:** 아래 사례는 통과 *예시*다. 같은 결과라도 다른 표현으로 도출 가능. **원리를 따랐는지가 정답이지, 표현이 일치하는지가 정답이 아니다.**

---

## 1. 중고거래 (핵심 비즈니스)

### 1-1. 캠페인 결과 후보 (1줄로 적기 — 자기 캠페인에 맞게 새로 적을 것)
- 내 물건이 우리 동네에서 얼마에 거래되는지 확인한다
- 안 쓰는 옷을 우리 동네 이웃에게 직접 판다
- 3분 안에 첫 거래글을 등록한다
- 이사 전 가구를 동네에서 정리한다
- 우리 동네에 비슷한 매물이 있는지 둘러본다

### 1-2. 헤드 도출 사례 (§3 패턴 B "상황→의외 결과" 활용)

| 캠페인 상황 | 헤드 사례 (참고) |
|---|---|
| 옷장 정리 | 안 쓰는 옷,\n이웃이 찾고 있어요 |
| 이사 | 이사 전 마지막,\n동네에서 정리 |
| 재발견 | 잊고 있던 물건도\n누군가의 보물 |
| 시급성 (§3 패턴 D 혼합) | 지금 이 순간에도\n이웃이 찾아요 |

Wide thin (1줄): 이웃이 찾고 있어요 → / 이사 전 당근 → / 누군가의 보물이 돼요 / 이웃이 찾아요 →

### 1-3. 서브 도출 사례
- 우리 동네 이웃과 당근에서 만나요
- 안 쓰는 물건도 누군가에겐 필요해요
- 내 동네 근처 127명이 활동 중
- 직거래 평균 3분, 동네라서 빠르게

### 1-4. CTA 도출 사례 (§5 작동 원리 → CTA)

| 캠페인 결과 (1줄) | 적용 후킹 패턴 | CTA 사례 |
|---|---|---|
| 내 물건의 동네 시세를 확인한다 | Personal + Curiosity | 내 시세 보기 (5자) |
| 3분 안에 거래글을 등록한다 | Specific time | 3분이면 등록 (6자) |
| 우리 동네 이웃에게 직접 판다 | Personal·Local | 이웃에게 팔기 (6자) |
| 동네 비슷한 매물을 둘러본다 | Local + Curiosity | 동네 매물 보기 (6자) |

→ 위는 *적용 사례*. 같은 결과라도 "내 시세 알기" 등 다른 도출 가능. §5-3 자가 검증 6개 통과하면 OK.

## 2. 당근페이 / 금융 송금

### 2-1. 캠페인 결과 후보
- 계좌번호 없이 이름만으로 이웃에게 송금한다
- 직거래 후 그 자리에서 바로 송금한다
- 송금 한 건을 1초 안에 처리한다
- 우리 동네 이웃에게 안전하게 송금한다

### 2-2. 헤드 도출 사례 (§3 패턴 D "구체적 수치/장소" 활용)

| 캠페인 상황 | 헤드 사례 |
|---|---|
| 간편송금 | 계좌번호 없이\n이름만으로 송금 |
| 직거래 동시 | 직거래 그 자리,\n바로 송금까지 |
| 안전 (§3 패턴 C 혼합) | 믿을 수 있는\n이웃끼리 거래 |

### 2-3. 서브 도출 사례
- 직거래 후 바로 송금, 당근페이로 안전하게
- 계좌번호 묻지 않아도 돼요
- 우리 동네 이웃끼리 빠르게

### 2-4. CTA 도출 사례

| 캠페인 결과 (1줄) | 적용 후킹 패턴 | CTA 사례 |
|---|---|---|
| 이름만으로 송금한다 | Specific (frictionless) | 이름으로 송금 (6자) |
| 1초 안에 송금한다 | Specific time | 1초 송금하기 (6자) |
| 우리 동네 이웃에게 송금한다 | Personal·Local | 이웃에게 송금 (6자) |
| 직거래 후 바로 결제한다 | Specific time | 거래 후 송금 (6자) |

## 3. 동네생활 / 커뮤니티

### 3-1. 캠페인 결과 후보
- 우리 동네 이웃들이 지금 어떤 글을 올렸는지 본다
- 동네 맛집 추천을 이웃에게 받는다
- 옆집 이웃과 가벼운 대화를 시작한다
- 우리 동네 실시간 소식을 받는다

### 3-2. 헤드 도출 사례 (§3 패턴 A "질문→공감", 패턴 C "이웃 관점" 활용)

| 캠페인 상황 | 헤드 사례 |
|---|---|
| 이웃 소통 | 옆집 이웃이\n뭐하고 있을까? |
| 동네 정보 | 우리 동네에서\n무슨 일이 있을까? |
| 맛집 추천 | 동네 맛집도\n이웃이 추천 |

### 3-3. 서브 도출 사례
- 역삼동 근처 이웃들이 이야기 중
- 우리 동네 소식을 실시간으로
- 동네 이웃 127명이 글을 올렸어요

### 3-4. CTA 도출 사례

| 캠페인 결과 (1줄) | 적용 후킹 패턴 | CTA 사례 |
|---|---|---|
| 우리 동네 이웃 글을 본다 | Local + Curiosity | 동네 글 보기 (5자) |
| 이웃과 가볍게 인사한다 | Personal·Local | 이웃 만나기 (5자) |
| 동네 맛집 추천을 받는다 | Local + Benefit | 맛집 추천 받기 (6자) |
| 우리 동네 실시간 소식을 받는다 | Local | 동네 소식 받기 (6자) |

## 4. 신규 유저 유치 / 리텐션

### 4-1. 캠페인 결과 후보
- 첫 가입 사용자가 첫 거래글을 3분 안에 올린다
- 오랜만에 돌아온 사용자가 우리 동네 새 매물을 본다
- 우리 동네 이웃들의 활동을 처음 둘러본다

### 4-2. 헤드 도출 사례 (§3 패턴 D "구체적 수치/장소", 패턴 C "이웃 관점")

| 캠페인 상황 | 헤드 사례 |
|---|---|
| 첫 거래 | 첫 거래까지\n평균 3시간 |
| 복귀 | 이웃들이\n당신을 기다려요 |
| 시작 | 첫 등록까지\n3분이면 충분해요 |

### 4-3. 서브 도출 사례
- 지금 동네 이웃 127명이 활동 중
- 첫 거래까지 평균 3시간

### 4-4. CTA 도출 사례

| 캠페인 결과 (1줄) | 적용 후킹 패턴 | CTA 사례 |
|---|---|---|
| 3분 안에 첫 거래글을 등록한다 | Specific time | 3분이면 등록 (6자) |
| 우리 동네 이웃을 둘러본다 | Local + Curiosity | 동네 둘러보기 (6자) |
| 이웃과 첫 인사를 한다 | Personal·Local | 이웃 만나기 (5자) |
| 우리 동네 새 매물을 본다 | Local + Curiosity | 새 매물 보기 (5자) |

## 5. 시즈널 / 이벤트

### 5-1. 캠페인 결과 후보 (계절별)
- **봄:** 안 입는 겨울옷·이사 가구를 동네에서 정리한다
- **여름 (이사철):** 큰 가구·여름 가전을 동네에서 정리한다
- **가을·겨울:** 여름옷을 정리하고 겨울옷을 꺼낸다 / 우리 동네 이웃과 따뜻한 거래를 한다

### 5-2. 헤드 도출 사례 (시즌 + §3 패턴 B / D)

| 시즌 | 헤드 사례 |
|---|---|
| 봄 (정리) | 옷장에 잠든 옷,\n이웃의 옷장으로 |
| 여름 (이사철) | 큰 가구도\n우리 동네에서 |
| 가을·겨울 (정리) | 겨울옷 꺼낼 때\n여름옷 정리도 |
| 겨울 (정서) | 따뜻한 겨울,\n이웃과 나누기 |

### 5-3. CTA 도출 사례 (시즈널은 시급성 강조 — Specific time + Local 권장)

| 캠페인 결과 (1줄) | 적용 후킹 패턴 | CTA 사례 |
|---|---|---|
| 이번 봄에 옷을 정리한다 | Specific time + Local | 봄맞이 정리 (5자) |
| 이사 전 가구를 정리한다 | Specific time | 이사 전 정리 (5자) |
| 겨울옷 거래글을 올린다 | Specific time | 겨울옷 등록 (5자) |
| 동네 이웃과 따뜻한 거래를 한다 | Personal·Local | 이웃과 거래 (5자) |

## 6. 절대 금지 (요약 — 상세는 foundation-voice-tone.md §5-3 + §6)

| 금지 카테고리 | 예 |
|---|---|
| 미완성형 명사 토막 (CTA에서 자주 발생) | 동네 핫이슈 / 내 동네 지금 / 혜택 |
| "공짜로 ~" 표현 | 공짜로 팔기 / 공짜로 받기 / 공짜로 구하기 |
| 외국어·외래 약어 | OK / Click / Now / Free / GO |
| 과장·검증 불가 | 최고의 / 역대 / 1등 / 단 하나의 |
| 클리셰 광고체 | 놀라운 / 당신의 삶을 바꿀 / ~의 세계 |
| 영어 직역체 | 영어 관용 표현을 어색하게 옮긴 한국어 |
| 기능명 단순 호출 (CTA) | 당근 열기 / 당근 시작하기 / 당근 설치하기 |

→ 위 중 하나라도 해당되면 즉시 재작성. 검증은 foundation-voice-tone.md §5-3 (CTA 6개) + §7 (카피 패키지 9개).

## 7. 새 캠페인을 만나면

이 파일에 카테고리가 없는 새 캠페인 (예: 부동산 / 알바 / 자동차)이 들어오면:

1. 새 카테고리를 임시로 정의한다 (캠페인 결과 후보 1줄들 적기).
2. **`foundation-voice-tone.md` §3 + §5 원리만 가지고** 헤드·서브·CTA 도출.
3. §5-3 + §7 자가 검증 통과.
4. 통과한 결과를 이 파일의 새 카테고리로 추가 (PR 형태로 정식 등록 권장).

이 파일은 살아 있는 문서. 사례가 늘어날수록 voice-tone 원리의 일관된 적용이 누적된다.
