# layouts/ — 사이즈별 레이아웃 인사이트

## 폴더 목적

`layout-spec.md`가 비율(A/B/C/D)별 단일 패턴 1개씩만 담아 부족했음.
본 폴더는 **사이즈별 별도 md**에 실제 시안에서 학습한 3~4개 레이아웃 변형을 담는다.

## 진입 규칙

1. `LOCKED_SIZES.md` — 사이즈 10종 락. 본 폴더 안의 모든 작업이 이 10종에만 한정.
2. `INSIGHT_RULES.md` — 사이즈 무관 절대 룰 (L1~L7). 사이즈별 md 작성/배너 생성 시 항상 우선.
3. `{W}x{H}.md` — 사이즈별 인사이트. 학습 후 채움. 한 사이즈당 3~4개 레이아웃 변형 담는다.

## 사이즈별 md 기록 항목 — 화이트리스트 (이 외 기록 절대 금지)

각 변형(variant)당 다음만 기록한다. **이 화이트리스트 밖의 항목은 어떤 경우에도 기록하지 않는다.**

| 항목 | 기록값 |
|---|---|
| 글자박스 | `w, h, x, y` (변형 안의 각 텍스트 노드별 모두) |
| 로고 | `h, x, y` |
| CTA 박스 | 박스 유무 / 박스가 있으면 `w, h, color` |
| 출처 | `source: nodeId` (L9) |

**기록 절대 금지 항목:**
- 사진 위치/크기
- 장식 도형(원, 반원, 곡선, 블러 등) — 애초에 결과물에서 제거 (L8)
- 그라데이션 디테일
- 폰트 패밀리/굵기 (foundation-typography가 단일 진실 소스)
- padding 수치 (foundation-spacing이 단일 진실 소스, L4)
- 카피 텍스트 자체 (시안에서 다시 끌어오지 말 것 — copy-library / voice-tone이 정답)

## 사이즈별 md 표준 골격

```md
# {W}×{H}

> 카테고리: {A|B|C|D}

## Variant 1
- source: 8605:xxxx
- 헤드: w=○, h=○, x=○, y=○
- 서브: w=○, h=○, x=○, y=○
- 로고: h=○, x=○, y=○
- CTA: 박스 있음, w=○, h=○, color=○   # 또는 "박스 없음"

## Variant 2
...
```

사이즈당 변형 3~4개. 각 변형은 출처 시안과 1:1 매칭 (L9). 변형끼리 디자인 합성·혼합 금지.

## 새 세션에서 학습 이어가기 — 표준 한 줄 포맷

새 세션 시작 시 사용자가 던질 한 줄:

```
#배너학습 figma=https://www.figma.com/design/CVeyCAgnLzNqGPbKlHh8wN/HANSY?node-id=8605-3281
```

이 한 줄이면:
- 사이즈 10종 락(`LOCKED_SIZES.md`) 적용
- L1~L7 룰(`INSIGHT_RULES.md`) 적용
- 피그마 페이지에서 사이즈별로 추출 → 본 폴더의 사이즈별 md 채움

## 학습 워크플로우 (새 세션 안에서)

> ❌ **스크린샷 사용 금지** (`get_screenshot` 사용 금지). 수치 도구만: `get_metadata` / `get_design_context`.

| # | 단계 | 도구 |
|---|---|---|
| 1 | 데스크톱 Figma에서 한 사이즈의 모든 변형 다중 선택 | (사용자) |
| 2 | `get_design_context` 호출 → 텍스트 노드의 w/h/x/y, 로고 노드의 h/x/y, CTA 부모 type/사이즈/색상 추출. 출처 nodeId도 같이 기록 | (Claude) |
| 3 | L1~L9 룰 위반 시 해당 변형은 제외 (특히 L8 장식원 발견 시 결과물에서 제거 표기) | (Claude) |
| 4 | 사이즈별 md에 기록 — **화이트리스트 항목만** | (Claude) |
| 5 | 다음 사이즈로 사용자가 selection 변경 | (사용자) |
| 6 | 10사이즈 모두 끝나면 commit | (Claude) |

**FIX 케이스 제외:** 사용자가 트리거 한 줄에 `exclude=NodeName1,NodeName2` 명시하면 해당 노드는 학습 대상에서 자동 제외. (예: `exclude=Moloco_Native_720x1280`)

## 절대 금지

- 사이즈별 md를 비어있는 채로 미리 생성하지 않는다 (학습 후에만 채움).
- 사이즈를 임의로 추가/제거하지 않는다 (LOCKED_SIZES.md 참조).
- 시안의 디자인을 임의로 섞거나 변형하지 않는다 (각 변형은 출처 시안과 1:1 매칭, L9).
- 학습 시 `get_screenshot` 사용 금지 — 수치 도구만.
- 화이트리스트 외 항목(사진, 장식, 그라데이션, 폰트 패밀리, padding, 카피 텍스트 등) 기록 금지.
- 장식원 발견 시 변형의 디자인에 포함시키지 않는다 (L8). 결과물에서 제거.
