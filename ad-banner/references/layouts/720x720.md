# 720×720 — Square

5개 시안.

1. Moloco_Native `head 45,54 433×300 fp=80` — 좌상 큰 헤드 + 좌하 로고, CTA 없음
2. Moloco_Native `head 40,133 383×252 fp=69` — 좌중상 헤드 + 좌하 로고, CTA 없음
3. Moloco_Native `head 61,289 420×48 fp=37` — 가운데 작은 헤드 + 좌하 로고, CTA 없음
4. PickUp `head 157,655 355×50 fp=37` — 하단(CTA bar 위) 헤드 + 좌중간 로고 + 풀와이드 CTA bar
5. baro `head 124,638 414×65 fp=48` — 하단 헤드 + 좌상 로고 + 풀와이드 CTA bar

## 핵심 다양성
- 헤드 위치 4가지: 좌상 / 좌중상 / 가운데 작은 / 하단(CTA 위)
- 폰트 37~80px
- CTA 있음: 2개, 없음: 3개
