# Foundation: Voice & Tone (광고 배너용)

> **출처**
> - https://seed-design.io/docs/foundation/voice-and-tone
> - https://seed-design.io/docs/foundation/writing
>
> SEED 두 페이지는 앱 UI 텍스트 기준이라 **길고 설명적**. 배너 카피는 6~20자 안에 보이스를 압축해야 하므로 핵심만 추렸다. 이 파일에 없는 규칙은 SEED 원문을 따른다.

---

## 0. 한 줄 정의

당근 voice = **활기차고 친절한** + **명확한·이해하기 쉬운·사려깊은**.
배너 카피는 이 보이스를 **6~20자 안**에 압축해야 한다.

---

## 1. SEED Voice & Tone 원문 (Principle)

**Service Usability**
- 사용자 행동을 이끌어 목적 달성을 도움
- 누구나 쉽게 사용 가능
- 신뢰할 수 있는 공간

**Brand Engagement**
- 지역사회·이웃에 애정 가지게 함
- 이웃의 존재를 알려 활발한 교류 유도

**Voice Tone:** 활기차고 자신감 있는, 이야기하듯 친근한.

## 2. SEED Writing 11개 룰 → 배너 적용 매트릭스

| Writing 룰 (SEED) | 배너 적용 | ✅ | ❌ |
|---|---|---|---|
| Familiar (익숙한 단어) | 한자어·기술용어 금지 | 끌어올리기 | 끌올 |
| Honorifics 최소 | "~해요" 체 | 찾고 있나요 | 찾고 계신가요 |
| Numbers 아라비아 | 한글 수 금지 | 이웃 127명 | 이웃 백이십칠 명 |
| Function purpose > name | 기능 목적 표현 | 채팅으로 거래하기 | 채팅하기 |
| Positive sentences | 긍정문 우선 | 한 번만 변경 가능 | 한 번 이상 변경 불가 |
| Active sentences | 능동문 | 이웃이 찾아요 | 찾아지고 있어요 |
| User actions | 사용자 행위 | 거래 후기를 보냈어요 | 작성 완료 |
| Emotions (사려깊게) | 마음에 와닿게 | (감정 담은 표현) | 처리·완료 같은 시스템어 |
| Focus on one purpose | 한 카피 = 한 메시지 | (분리) | 한 카피에 두 가지 |
| Local Community | 동네/이웃 키워드 1회 | 우리 동네 이웃 127명 | (동네 키워드 없음) |
| Spaces (띄어쓰기) | 기능명·서비스명·상태값은 붙여쓰기 | 예약중 / 동네인증 | 예약 중 / 동네 인증 |
| Periods (20pt 이상) | **헤드·CTA 마침표 없음** | 이웃이 찾아요 | 이웃이 찾아요. |

**Exclamation marks:** 카피당 0~1개. 2개 이상이면 의미 잃음.

## 3. 배너 헤드 패턴 (검증된 4가지)

### 패턴 A — 질문 → 공감
`[명사] + [상태 질문]`
- "옷장 안에 / 안 입는 옷 있어요?"
- "혹시 이 물건, / 쓰지 않은 지 오래됐죠?"

### 패턴 B — 상황 → 의외의 결과
`[상황] / [결과]`
- "안 쓰는 옷, / 이웃이 찾고 있어요"
- "우리 집 잠자던 물건, / 동네에서 바로 거래"

### 패턴 C — 이웃 관점
`[이웃이 ~하고 있다] / [내 행동 단서]`
- "누군가 찾고 있어요, / 당신의 그 물건"
- "옆집 이웃이 / 이 물건을 기다려요"

### 패턴 D — 구체적 숫자/장소
`[구체 시간·장소] + [행동]`
- "지금 3분이면 / 동네 이웃과 거래"
- "우리 동네 근처 / 당근 이웃 127명"

## 4. 배너 헤드 길이 룰

| 비율 | 줄 수 | 한 줄 글자 수 | 비고 |
|---|---|---|---|
| Wide thin (≥2.5) | 1줄 | 6~10자 | 끝에 `→` 권장 |
| Square (0.9~1.3) | 2줄 | 4~8자 | |
| Landscape (1.3~2.5) | 2줄 | 5~9자 | |
| Portrait (<0.9) | 2줄 | 5~9자 | |

**상한:** 가장 긴 줄 = 9자. 그 이상은 가독성 붕괴 (Karrot Sans Heavy + letter-spacing -3% 기준 실측).

## 5. CTA 라벨 작동 원리

CTA는 동사 토막이 아니라 **"클릭하면 무엇이 일어나는가"를 3~6자로 압축한 약속**이다. 약속이 보이지 않으면 클릭 동기가 없다. "당근 열기"·"지금 시작하기" 같은 *기능 호출형*은 약속이 보이지 않아 CTA로 부적격.

### 5-1. 4가지 후킹 패턴 (최소 1개 포함)

| 패턴 | 작동 원리 | 핵심 질문 |
|---|---|---|
| Benefit | 클릭 후 얻는 결과를 명시 | "클릭하면 뭐가 좋아지나요?" |
| Specific | 구체 수치(시간·개수)로 마찰을 낮춤 | "얼마나 빠르게 / 얼마나 많이?" |
| Personal·Local | 내 / 우리 동네 / 이웃을 호명 | "이게 누구의 일인가?" |
| Curiosity | 모르는 정보를 들여다보게 만듦 | "지금 모르는 걸 보여준다" |

조합 권장 (예: Personal + Curiosity = "내 시세 보기").

### 5-2. CTA 생성 4단계 프로세스

1. **결과 확정** — 클릭 후 사용자가 도달하는 결과를 1줄로 적는다.
   예: "내 노트북이 우리 동네에서 거래되는 시세를 확인한다"
2. **결과를 동사+목적어로 압축** — 의미가 통하는 최소 단위.
   예: "내 시세를 본다"
3. **후킹 패턴 적용** — §5-1의 4가지 중 1개 이상.
   예: Personal + Curiosity → "내 시세 보기"
4. **3~6자 압축, 단 의미는 완성형** — 동사+목적어 단위는 절대 자르지 않는다.

> **글자수 줄이려고 의미를 잘라서 명사 토막을 만들면 안 된다.** "내 동네 지금" / "동네 핫이슈" / "혜택" 같은 명사 토막은 약속이 아니므로 CTA가 아니다.

### 5-3. CTA 자가 검증 (출력 전 6개)

- [ ] 명사 토막이 아님 — **동사형(~기) 또는 행동 함의 한자어(송금·등록·정리·거래)로 끝남.** 핫이슈·정보·혜택·지금 같은 *상태/대상 명사*로 끝나면 X
- [ ] 클릭 후 일어나는 결과가 보임 — 기능 이름 단순 호출 X
- [ ] §5-1 4가지 후킹 패턴 중 1개 이상 포함
- [ ] **한글만** — OK / Click / Now / GO / Free 같은 외국어·외래 약어 0
- [ ] 공짜·최고·역대·1등 같은 과장/검증 불가 표현 0
- [ ] 3~6자 안에 들어가되 의미가 완성형 (글자수 줄이려 자르지 않음)
- [ ] 마침표 없음 (Periods 룰)

하나라도 NO → 재작성. 캠페인·카테고리가 달라도 동일 적용.

## 6. ❌ 절대 금지 (즉시 재작업)

| 카테고리 | 예시 |
|---|---|
| 클리셰 광고체 | 놀라운 / 최고의 / 혁신적인 / 당신의 삶을 바꿀 |
| ~의 시리즈 | ~의 세계 / ~의 향연 / ~의 시작 |
| 영어 직역체 | 영어 관용 표현을 어색하게 그대로 옮긴 한국어 (자가 판단) |
| 추상 명사 나열 | 가치있는 순환 / 연결의 시작 |
| 느낌표 남발 | 한 카피에 2개 이상 |
| 이중피동 | 보여지는 / 찾아지는 |
| 과한 존칭 | 구매하실 수 있으십니다 |
| 추상 감탄 | 봄의 따뜻함 / 당신과 함께하는 일상 |
| 축약어·유행어·은어 | 끌올 / 당근해요 / 갓성비 |
| 미완성형 명사 토막 | 동네 핫이슈 / 내 동네 지금 / 혜택 (특히 CTA에서, 약속 X) |
| "공짜로 ~" 표현 | 공짜로 팔기 / 공짜로 받기 / 공짜로 구하기 (저렴한 인상 + 검증 어려움) |
| 외국어·외래 약어 | OK / Click / Now / Free / GO (한글 우선 룰) |
| 기능명 단순 호출 (CTA) | 당근 열기 / 당근 시작하기 / 당근 설치하기 (CTA 약속 안 보임) |
| 과장·검증 불가 표현 | 최고의 / 역대 / 1등 / 단 하나의 |

## 7. 자가 검증 체크리스트 (출력 전 9개 전부 YES)

- [ ] 헤드 2줄 이내, 각 줄 4~9자 (Wide은 1줄 6~10자)
- [ ] 구체적 사물·상황·숫자 포함
- [ ] "우리 동네" / "이웃" / "동네" 키워드 1회 이상
- [ ] 능동문
- [ ] "~해요" 체 (존칭 최소화)
- [ ] 클리셰 광고체 0개
- [ ] 영어 직역체 0개
- [ ] 서브가 헤드를 보완 + 행동 단서 포함
- [ ] CTA는 §5-3 자가 검증 6개 전부 통과 (명사 토막 아님 / 후킹 패턴 / 한글만 / 과장 0 / 완성형)

하나라도 NO → 재작성.
